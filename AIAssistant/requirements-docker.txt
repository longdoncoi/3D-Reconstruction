# It mirrors AIAssistant/requirements.txt with exactly one difference: the
# runtime lock resolves ``faiss-gpu`` for every non-Windows platform, so the
# slim CPU image would pull a CUDA wheel it can never use. The container is a
# CPU-only runtime, so it pins ``faiss-cpu``.
#
# ``tests/unit/test_lockfile_sync.py`` pins the relationship: every package
# here must also be a direct requirement of the runtime file, so the two
# lists cannot drift apart.
#
# Hash-pinned for production:
#   uv pip compile requirements-docker.txt --python-version 3.11 --universal \
#       --generate-hashes -o requirements-docker.lock
#   pip install --require-hashes -r requirements-docker.lock
