# ─── AIAssistant test dependencies ────────────────────────────────────────────
# Dependency set for the offline unit/contract/integration test suite.
#
# The suite never loads a model: llama-cpp-python, sentence-transformers and
# llama-index are faked (sys.modules doubles). The RAG *index* is different —
# tests/unit/test_rag_corpus_mini.py and tests/unit/test_server_rag_wiring.py
# build a real FAISS + BM25 index on a mini corpus on purpose ("no mocks of the
# index"), so numpy/faiss-cpu/rank-bm25 are hard requirements: without them
# those tests error out and the coverage gate in .github/workflows/
# Build-Python-ci.yml cannot reproduce the 100% floor measured locally.
#
# Two more packages are real, not faked, because the tests that exercise them
# exercise the *real* integration and skip (or error) when the package is
# absent — which also drops coverage below the 100% floor:
#   - huggingface_hub: llm/model_loader.download_if_missing lazy-imports it;
#     its lifecycle tests patch hf_hub_download, which needs it importable.
#   - mcp: the adapter integration tests (real session manager + tool dispatch)
#     run only when mcp is present; without it they skip and adapters/mcp.py
#     plus the mcp branches in agents/completion.py go uncovered.
#
#   pip install --require-hashes -r AIAssistant/requirements-test.lock
#   cd AIAssistant && python -m unittest discover -s tests -p "test_*.py"
#
# requirements-test.lock là bản hash-pinned của file này (sinh bởi
# `uv pip compile requirements-test.txt --python-version 3.11 --universal
# --generate-hashes`); CI cài đúng lock đó với --require-hashes (ADR 0023).
